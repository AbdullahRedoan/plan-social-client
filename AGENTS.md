## Rendering: Cache Components is enabled

`next.config.ts` sets `cacheComponents: true` and `partialPrefetching: true`, so routes use Partial Prerendering and uncached data outside a boundary fails dev/build:

- Wrap uncached async work and runtime APIs (`cookies()`, `headers()`, `fetch`, `params`, `searchParams`) in `<Suspense>`, or move the work into a `"use cache"` function (pair it with `cacheLife`/`cacheTag`).
- `params` and `searchParams` are Promises. Awaiting a dynamic value at a layout/page top level prevents that part from prerendering; defer the await below a `<Suspense>` boundary where possible.
- Do not add these route segment exports — they are removed when Cache Components is on: `dynamic`, `dynamicParams`, `revalidate`, `fetchCache`, and `experimental_ppr`. Remove `runtime` exports too, including `runtime = "nodejs"`.
- `Math.random()`, `Date.now()`, and `crypto.randomUUID()` are guarded during prerender. For per-request values call `await connection()` inside a `<Suspense>` boundary, or cache the value with `"use cache"`.
- `revalidateTag` requires a second `cacheLife` argument in Next 16 (e.g. `revalidateTag("posts", "max")`).

## UI and styling

- Tailwind v4 is CSS-first: there is no `tailwind.config.*` or PostCSS config. Tokens, `@theme`, and dark mode live in `src/app/globals.css`. CSS is compiled by `@tailwindcss/turbopack` through `turbopack.rules` in `next.config.ts`; don't add a competing Tailwind setup.
- shadcn is configured with `style: "base-nova"` on **Base UI** (`@base-ui/react`), not Radix. Add components with `npx shadcn add <name>` rather than pasting Radix-based snippets.
- Base UI components use a `render` prop, not Radix's `asChild`.
- `cn` is the `cn` npm package (drop-in for `clsx` + `tailwind-merge`), re-exported from `@/lib/utils`. Don't install `clsx` or `tailwind-merge`.
- Icons come from `lucide-react`.

## Conventions

- Import alias: `@/*` → `src/*`.
- Route prop types are generated by Next.js: use the global `PageProps<"/route">` / `LayoutProps<"/route">` helpers (see `src/app/layout.tsx`) instead of hand-writing `params`/`searchParams` types. They live in `.next/types`; run `npm run dev` or `npm run build` after a clean clone to generate them.
- React Compiler is enabled (`reactCompiler: true`); don't add `useMemo`/`useCallback`/`React.memo` for performance by default.
